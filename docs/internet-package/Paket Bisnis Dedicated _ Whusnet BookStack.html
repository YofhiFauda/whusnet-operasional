    Keterangan :

    • Router : Perangkat Mikrotik untuk manajemen Koneksi. 
    • AP : Akses Point Untuk memperluas jaringan supaya lebih luas area jangkauan signal. 
    • Jika ingin Penambahan IP Publik tambahan biaya Rp 50.000 /IP Address.
    • Jatah Kabel 10Meter Per AP

    Fitur di semua paket :

    • Jaminan MTTR 4 Jam Dari Terbitnya Tiket Gangguan (*Mohon ke pelanggan untuk berikan Akses tim teknis Whusnet 24/7 ke server pelanggan)
    • Pelanggan Termonitor 24Jam/7 
    • 24jam HelpDesk Khusus dan Jalur khusus Telepon agar tidak perlu mengantre dengan pelanggan Ritel.
    • Pelanggan tidak perlu pusing setting router, whusnet yang melakukan semuanya bahkan termasuk mengganti paswords.
    • MRTG Monitoring
    • Koneksi Point To Point Ke router Distribusi ISP
    • 2 Jalur Koneksi
    • Akses Konten Internasional lebih besar di banding paket broadband.
    • SLA 99%, Bandwidth 1:1


    Syarat Ketentuan :

    • Harga Belum termasuk PPN.
    • Pembayaran Disarankan Transfer.
    • Gratis Biaya Installasi jika pelanggan membayar 1 tahun di muka. 

    Penawaran Jika nego (Pilih salah satu):
    1. Bonus Backup Daya Router & AP Untuk paket Dedicated 500Mbps & 1Gbps
    2. Batas Harga Bawah : 100Mbps Rp 3.000.000, 250Mbps Rp 5.500.000, 500Mbps Rp 11.000.000, 1Gbps Rp 21.000.000
