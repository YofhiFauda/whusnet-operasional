# User Flow: Master Paket Internet

Dokumen ini mendeskripsikan langkah-langkah pengguna (User Flow) dalam menggunakan fitur Master Paket Internet.

## Skenario Utama: Melihat dan Mencari Paket Internet

**Aktor**: Admin / Pegawai

**Pre-condition**: User sudah login ke dalam aplikasi dan berada di area dashboard.

**Langkah-langkah**:
1. User mengklik menu **Master Data** di Sidebar.
2. User memilih sub-menu **Paket Internet**.
3. Sistem memuat daftar paket internet dari database beserta detail harganya dan menampilkannya di layar.
4. User dapat memasukkan kata kunci pada kotak pencarian (Misal: "Net138") untuk memfilter daftar.
5. User juga dapat memilih filter Kategori melalui Dropdown (Misal: "Home Broadband").
6. Sistem memuat ulang data di tabel menyesuaikan filter yang diberikan user.

**Post-condition**: User menemukan informasi paket internet yang dicari dan memahami spesifikasi atau harga dari paket tersebut.
